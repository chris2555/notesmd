# Changelog

All versions follow [semver](https://semver.org/): `MAJOR.MINOR.PATCH`.

## 0.1.0 — 2026-11-01

First published version.

- Masonry board (flex columns) and list view.
- Markdown notes with front matter; one note = one file in `~/Notas-notesmd`.
- Labels, instant search, pinned notes, archive and trash with undo.
- Editor with Markdown preview and formatting bar.
- YouTube-style dark theme and light theme, with nine paper colors.
- Autosave, keyboard shortcuts and desktop launcher.
- `.deb` and `.tar.gz` packaging, and automatic release on `v*` tag push.
