# Cambios

Todas las versiones siguen [semver](https://semver.org/lang/es/): `MAJOR.MINOR.PATCH`.

## 0.1.0 — 2026-11-01

Primera versión publicada.

- Tablero en mosaico (columnas flex) y vista de lista.
- Notas en Markdown con frontmatter; una nota = un archivo en `~/Notas-notesmd`.
- Etiquetas, búsqueda instantánea, fijadas, archivo y papelera con deshacer.
- Editor con vista previa Markdown y barra de formato.
- Tema oscuro tipo YouTube y tema claro, con nueve colores de papel.
- Guardado automático, atajos de teclado y lanzador de escritorio.
- Empaquetado `.deb` y `.tar.gz`, y release automática al empujar un tag `v*`.
